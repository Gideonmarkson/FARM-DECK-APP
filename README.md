## 📖 Overview

**Farm Deck** is a modern, mobile-first agricultural marketplace and supply chain platform tailored specifically to the Lagos food economy. It bridges the gap between rural smallholder farmers, central food hubs (like Mile 12, Oyingbo, Agege, Ketu, and Epe Fish Market), commercial bulk buyers (restaurants, caterers, hotels), and everyday urban households.

By standardizing traditional Nigerian measurement units (*Paint Buckets (4L)*, *Derica (800g)*, *Tubers*, *Bunches*, *Gallons (4L/25L)*) and offering native logistics integration, Farm Deck removes middlemen markups, guarantees produce freshness, and stabilizes food pricing across Lagos State.

## ✨ Core Features & Modules

### 🛒 1. Hyperlocal Consumer Marketplace
- **Lagos Native Sourcing Units**: Buy agricultural commodities in standard local metrics (Paint Buckets, Derica, Tubers, Sacks, Bunches, Gallons).
- **All 20 Lagos LGAs Covered**: Instant delivery fee calculation and distance estimation based on user location (Ikorodu, Ikeja, Eti-Osa/Lekki, Epe, Badagry, Alimosho, Kosofe, etc.).
- **Organized Market Directory**: Filter produce directly from over 60+ verified markets across all 20 LGAs.
- **Produce Freshness Guarantee**: Grade A+ (Harvested Today at Dawn) and Grade A (Early Morning Northern / Regional Truck Arrivals).

### 📋 2. Buyer Demand Board (RFQ System)
- **"Post a Need" Workflow**: Households and commercial eateries broadcast public Demand Requests specifying produce type, quantity, target budget (₦ NGN), deadline, and Lagos neighborhood.
- **Seller Demand Spotter Feed**: Farmers and market stallholders browse live demand, spot nearby requests, and send counter-quotes or stock offers.
- **Multi-Offer Evaluation**: Buyers compare competing bids from verified sellers and award contracts in one tap.

### 💬 3. In-App Direct Market Chat & Price Negotiation
- **Real-Time Direct Messaging**: Secure channel between buyers and farmers/vendors before and after purchase.
- **Photo Upload & Camera Integration (`+` button)**: Upload custom harvest photos directly from phone/PC storage or pick from live market stall snapshots.
- **Interactive Price Negotiation Cards**: Vendors send counter-proposals directly inside the chat thread with a 1-click **"Accept & Add to Cart"** button.
- **Read Receipts & Verified Seller Badges**: Instant trust verification with stall numbers and market location badges.

### 🏪 4. Vendor & Smallholder Farmer Hub
- **60-Second Fast Listing**: Add new farm produce with units, freshness grades, pricing, and photo uploads.
- **Live Inventory & Fulfillment Dashboard**: Track active orders, pending payouts, stock levels, and customer ratings.
- **Market Cooperative Integration**: Built for individual stallholders, farming families, and agricultural co-ops.

### 🚚 5. 3PL Motorcycle & Van Dispatch Hub
- **Multi-Stage Tracking**: Real-time progress updates (*Order Placed &rarr; Vendor Packing &rarr; Rider Dispatched &rarr; In Transit &rarr; Delivered*).
- **Rider Vehicle Allocation**: Box bikes for perishable produce, aerated water containers for live catfish, and vans for bulk sacks of yam/cassava.

### 📈 6. Daily Lagos Commodity Price Index
- **Live Market Price Tracking**: Real-time rate comparisons across 8 major food hubs (Mile 12, Oyingbo, Ketu, Sangotedo, Agege, Badagry, Ikorodu, Epe).
- **24-Hour Price Trends**: Transparent commodity price changes (%) helping buyers avoid inflated middleman rates.

### 👨‍🍳 7. AI Chef & Smart Ingredient Calculator
- **Powered by Google Gemini 2.5 AI**: Input any Nigerian dish (*Jollof Rice, Egusi Soup, Efo Riro, Afang Soup, Banga, Pepper Soup, Fishermans Soup*).
- **Automated Ingredient Calculator**: Computes exact produce portions based on serving size and allows 1-click addition of all ingredients to the cart.

## 🛠️ Technology Stack

- **Frontend Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom agricultural palette (`#1b4332`, `#2e7d32`, `#f4f9f4`)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Backend Server**: [Express.js](https://expressjs.com/) with TypeScript (`server.ts`)
- **Artificial Intelligence**: [Google Gemini 2.5 API](https://ai.google.dev/) via `@google/genai`
- **Network Broadcasting**: Enabled via `--host 0.0.0.0` for local mobile testing over Wi-Fi

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18.0.0 or higher)
- `npm` or `yarn`

### 1. Installation
Clone or navigate to the repository directory and install the dependencies:
```bash
git clone <repo-url>
cd "FARM DECK"
npm install
```

### 2. Configure Environment Variables
Create a `.env` file in the root directory (optional for local mock mode):
```env
PORT=5173
GEMINI_API_KEY=your_google_gemini_api_key_here
```

### 3. Start the Development Server
```bash
npm run dev -- --host 0.0.0.0 --port 5173
```

- 💻 **On your PC / Desktop**: Open `http://localhost:5173/`
- 📱 **On your Mobile Device** *(connected to the same Wi-Fi network)*: Open `http://<your-ip-address>:5173/` (e.g., `http://10.195.0.49:5173/`)

### 4. Build for Production
```bash
npm run build
```

## 🔌 API Endpoints Summary

The Express backend (`server.ts`) provides RESTful endpoints:

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/produce` | Fetch all produce items with LGA and market filters |
| `GET` | `/api/demand-requests` | Fetch live buyer Demand Requests (RFQs) |
| `POST` | `/api/demand-requests` | Create a new buyer Demand Request |
| `POST` | `/api/demand-requests/:id/offers` | Submit a vendor stock offer to a demand request |
| `GET` | `/api/conversations` | Retrieve buyer/vendor direct chat threads |
| `POST` | `/api/conversations/:id/messages` | Send chat message, image upload, or counter-price |
| `GET` | `/api/market-prices` | Fetch daily Lagos commodity price index across markets |
| `POST` | `/api/orders` | Place a new order with 3PL dispatch tracking |
| `POST` | `/api/ai/calculate-ingredients` | Generate Nigerian recipe ingredients with Google Gemini AI |
